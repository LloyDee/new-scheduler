File format and validation

Required columns and values: Name, Phone, Email, Congregation, Privilege. Notes is optional. Headers can appear in any order; capitalization is ignored.

Phone must contain 10 digits. Use text cells for phone numbers in Excel to preserve leading zeros. Privilege: Elder, Ministerial Servant, or Publisher.

Optional department columns use Department: department name. Roles: Admin, Overseer, Assistant Overseer, Captain, Key Man, or Volunteer. Leave all department cells blank for No Department Yet.

Excel imports use the first worksheet. Formula and error cells are not accepted. Duplicate names or phone numbers in this event or file reject the entire import. Any invalid row rejects the entire file; no volunteers are saved.
